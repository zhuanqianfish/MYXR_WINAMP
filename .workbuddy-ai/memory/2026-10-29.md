# 2026-10-29 — MYXR WINAMP v0.8（MP4 支持 + 锁屏媒体控制）

## 做了什么

克隆 https://github.com/zhuanqianfish/MYXR_WINAMP 到 `E:/MyProjectsE/MYXR_WINAMP`（Windows 本机），
加了两块功能，versionCode 12→13 / versionName 0.7→0.8，本地已提交（commit `70e1e96`，**未 push**）。

### 1. MP4 / 视频支持
- `MainActivity.openPicker()` 改成 `setType("*/*")` + `EXTRA_MIME_TYPES={audio/*,video/*,application/ogg}`。
- 新增 `MediaProbe`（探测音频轨/视频轨/时长/内嵌封面或视频首帧），无音频轨的容器直接跳过并提示。
- 新增 `VideoWindowView`（275x116 逻辑像素的 "MYXR VIDEO" 窗口，TextureView）+ `VideoRenderer`
  （MediaCodec 解码到 Surface，**按音频播放头对齐帧**：超前等待/落后丢帧/偏差>1.5s flush 重对齐，
  1 秒内只对齐一次防空转；支持 `KEY_ROTATION` 旋转，手算 Matrix 等比缩放）。
- 有画面时自动隐藏均衡器窗口腾位置，回到纯音频自动还原（`updateVideoWindow`）。
- 音频仍然走 `PcmAudioEngine`，所以均衡器/频谱对 MP4 一样生效。

### 2. 锁屏 / 通知栏控制
- 新增 `PlaybackService`（前台服务 + `android.media.session.MediaSession` + `Notification.MediaStyle`
  + `AudioFocusRequest` + `ACTION_AUDIO_BECOMING_NOISY` + `PARTIAL_WAKE_LOCK`）。
- **播放列表归属从 Activity 迁到服务**；`WinampPlayer.Listener` 改成多播（服务一份、界面一份）。
- 界面改为 `startService + bindService`，所有传输控制走 `svc.play()/pause()/...`；
  服务通过 `PlaylistListener` 广播列表变化。
- 通知：封面（320px 上限，512 会踩 binder 1MB 事务上限）+ 上一首/播放暂停/下一首 + 进度。
- 新增 `res/drawable/ic_stat_winamp.xml` 与 `ic_media_{play,pause,prev,next}.xml`（纯白矢量）。

## 构建环境（本机新建）

- 本机**没有任何 JDK**，Android Studio 也没装，只有 SDK 在 `%LOCALAPPDATA%\Android\Sdk`（build-tools 35/36/37）。
- 装了 Temurin 17 到 `F:\tools\jdk-17.0.20.1+1`。
  ⚠️ Adoptium 官方源在国内只有 ~100KB/s，**清华镜像 `mirrors.tuna.tsinghua.edu.cn/Adoptium/` 秒下**。
- 新增 `build.sh`（一键构建），踩到三个 Windows 坑：
  1. `d8`/`apksigner` 是 `.bat`，`zipalign` 是 `.exe`；
  2. Git Bash 没有 `zip` → 用 python 重写整个 zip 补 classes.dex，
     **不能用 `'a'` 追加模式**（zipalign 会刷一屏 `header mismatch`），且 `resources.arsc` 必须保持 STORED；
  3. `~/.android/debug.keystore` 本机已存在，不用 keytool 现生成。
- 产物 `app-src/WinampClassic.apk`（1.2MB，debug 签名，apksigner verify 通过）。
